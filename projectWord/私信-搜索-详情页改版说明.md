# 私信、搜索、灵感详情页改版说明

> 更新时间：2026-09-23  
> 适用范围：前台私信页、灵感搜索页、灵感详情页  
> 说明：本文记录本轮已落地的正式代码改动，不只是设计预览。

## 一、私信页

### 1. 采用方案

采用方案 A「经典聊天流」。

### 2. 页面变化

- 私信页改为移动端单页结构，不再使用旧的左右双栏布局。
- 顶部显示标题、会话数量、未读数量。
- 新增昵称/消息内容搜索。
- 新增「全部 / 未读」筛选。
- 未读会话优先分组展示。
- 会话行展示头像、昵称、最后消息、时间、未读数量。
- 打开聊天后显示独立聊天页：
  - 返回会话列表
  - 对方头像与用户名
  - 消息气泡
  - 精确到分钟的消息时间
  - 输入框回车发送
  - 发送中状态
- 删除会话、清空全部聊天改为底部确认弹窗。
- 保留直达会话、已读上报、消息发送、会话删除和轮询能力。

### 3. 性能处理

- 轮询保持 3 秒，但加入并发保护，避免慢请求堆积。
- 页面不可见时暂停轮询请求。
- 打开会话后一次完成已读更新、消息加载和列表刷新。

### 4. 主要文件

- `frontend/src/pages/Messages.vue`
- `frontend/src/api/message.js`

### 5. 测试点

- 搜索昵称和消息内容。
- 切换全部/未读。
- 点击会话后自动清除未读。
- 发送后消息立即出现在聊天窗口。
- 删除会话和清空聊天。
- 从详情页直接进入某个会话后可以正常返回。

## 二、灵感搜索页

### 1. 采用方案

采用方案 B「视觉探索流」。

### 2. 页面变化

- 顶部使用搜索框、返回按钮和个人页入口。
- 初始页展示：
  - 搜索引导文案
  - 后台词云推荐词
  - 「正在流行」双列图片流
- 支持单列/双列切换：
  - 默认双列
  - 点击文字切换为单列
  - 再点击恢复双列
  - 搜索结果与热门图片同步切换
- 搜索结果展示：
  - 分类筛选
  - 图片结果卡
  - 收藏入口
  - 结果数量
  - 加载更多
- 返回结果页时清空关键词和筛选，回到探索页。
- 结果列表第一张固定为「我有一个灵感 +」创建引导卡：
  - 使用图片卡样式
  - 点击进入创建灵感
  - 未登录先跳登录
  - 原搜索结果排在该卡之后

### 3. 数据来源

- 热门词：`GET /api/inspire/public/word-cloud`
- 分类：`GET /api/inspire/public/categories`
- 热门灵感：`GET /api/inspire/public/list?sort=heat`
- 搜索：`GET /api/search/public`

### 4. 字体与交互修正

- 搜索页按钮不再使用 `font: inherit` 覆盖字号，改为只继承字体族。
- 单双列切换使用浅灰小字样式。
- 当前实现中：
  - 标题字号 `13.5px`
  - 单双列切换 `10px`
  - 搜索按钮 `12.5px`

### 5. 主要文件

- `frontend/src/pages/Search.vue`
- `frontend/src/api/inspire.js`

### 6. 测试点

- 点击热门词进入搜索结果。
- 分类筛选后重新查询。
- 点击单列/双列切换。
- 加载更多可追加第二页。
- 点击结果卡进入详情。
- 点击收藏选择收藏夹。
- 点击第一张「我有一个灵感 +」进入创建页。

## 三、灵感详情页

### 1. 编辑按钮位置

- 编辑按钮从作者卡片移动到详情页顶部右侧。
- 只有作者本人可见。
- 作者卡片只保留作者头像、昵称、发布时间和关注状态。
- 顶部返回、编辑、分享统一改为浅色描边样式，不再使用橙色实心按钮。

### 2. 评论输入

- 底部评论输入框提示改为：

```text
说点什么，回车发送
```

### 3. 评论排序

- 默认按热度。
- 单个文字按钮切换当前排序：
  - 当前显示「按热度」时，点赞高的评论在前。
  - 点击后切换为「按时间」，最新评论在前。
  - 再点击切回「按热度」。
- 热度排序规则：
  1. 评论点赞数降序
  2. 点赞数相同时按时间降序
- 时间排序规则：
  1. 评论创建时间降序
- 评论时间显示精确到分钟，例如：

```text
9月16日 19:17
```

### 4. 评论点赞

- 评论点赞改为真实接口持久化，不再只在前端本地切换。
- 点赞和取消点赞都会更新数据库中的 `like_count`。
- 列表返回时会带上当前用户是否已点赞。

接口：

```text
POST   /api/inspire/{inspireId}/comment/{commentId}/like
DELETE /api/inspire/{inspireId}/comment/{commentId}/like
GET    /api/inspire/{inspireId}/comments?sort=hot|time
```

### 5. 返回逻辑

- 不再无条件执行 `router.back()`。
- 如果历史来源是当前站点内部页面，返回上一页。
- 如果详情页是直接打开，或历史来源是旧端口/外部地址，则回首页。
- 避免点击返回后进入已失效的旧端口页面。

### 6. 评论种子数据

种子生成器已同步支持评论热度和互相回复：

- 主评论会生成不同点赞量。
- 回复也会生成点赞量。
- 回复可以指向其他回复，形成真实的「A 回复 B」链。
- 详情页重点灵感会生成 200～300 条评论。

本轮清库重建后实际生成：

- 详情页评论填充：处理 16 条灵感
- 新增评论：4083 条
- 种子用户：`user001`、`user002`、`user003`
- 默认密码：`112233`
- 管理员：`admin / 112233`

### 7. 数据库变化

评论表新增：

```sql
like_count INT DEFAULT 0
```

并增加热度排序索引：

```sql
KEY idx_inspire_deleted_hot (inspire_id, deleted, like_count, create_time)
```

新增评论点赞分表：

```text
comment_like_0 ~ comment_like_9
```

按 `user_id % 10` 分片。

## 一、设计令牌

文件 `frontend/src/styles/tokens.css`，在 `main.js` 全局引入。以后页面里不要再写死色值，统一 `var(--xx)`。

**间距**：`--sp-1` 到 `--sp-6` = 4 / 8 / 12 / 16 / 20 / 24px
**圆角**：`--radius-sm/md/lg/pill` = 8 / 12 / 16 / 999px
**字号**：`--fs-xs/sm/md/lg/xl` = 11.5 / 12.5 / 13.5 / 15 / 17px
**阴影**：`--shadow-sm/md/lg`

**中性色**（不随主题变）：`--c-bg` `--c-surface` `--c-text` `--c-text-2` `--c-text-3` `--c-danger`

**主题色**（随主题变）：

| 变量 | 用途 |
| --- | --- |
| `--c-primary` | 主色：按钮 / 选中态 / 强调文字 |
| `--c-primary-weak` | 主色极浅底：选中卡片背景 |
| `--c-primary-soft` | 主色浅底：标签 / 头像底 / 骨架屏 |
| `--c-primary-line` | 描边 / 分割线 |
| `--c-primary-hover` | hover 描边 |
| `--c-accent` / `--c-accent-weak` | 辅助色 |

## 二、三套主题

| key | 名称 | 主色 |
| --- | --- | --- |
| mint | 薄荷绿（默认） | #0f766e |
| orange | 暖橙 | #c2611f |
| morandi | 莫兰迪灰 | #6b7280 |

切换方式（`@/utils/theme.js`）：`initTheme()` 启动时调用、`applyTheme('orange')` 手动切、`localStorage.inspire_theme` 持久化。`applyTheme()` 只更新状态与本地存储，不修改 `<html>`；`Personal.vue` 根节点通过 `:data-theme="currentTheme"` 使用主题，因此**只有个人页受主题切换影响**，其他页面保持各自原有配色。

切换入口：个人页底部「主题」那行三个胶囊按钮（`id="p-theme"`）。

## 三、通用组件（`src/components/base/`）

所有基础组件已在 `main.js` 通过 `components/base/index.js` 全局注册，页面里直接写标签即可，不需要每页 import。

**AppCard** — 统一卡片：

```vue
<AppCard clickable padding="14px" @click="goDetail(id)">内容</AppCard>
```

支持 `variant="outline|flat|plain"`、`selected`、`clickable`，点击卡片会自动处理键盘 Enter / Space。

**AppState** — 列表三态统一（重点）：

```vue
<AppState :state="listState" :rows="3" empty-text="还没有内容" @retry="load">
  <!-- state === 'ready' 时才渲染 -->
</AppState>
```

- `loading` → 骨架屏（缩略图 + 两行文字，呼吸动画）
- `empty` → 图标 + 文案，可用 `#empty-action` 插槽
- `error` → ⚠️ + 「加载失败，请稍后重试」+ 重新加载按钮（触发 `@retry`）
- `ready` → 渲染默认插槽

支持自定义 `#loading` / `#empty` / `#error` 插槽；`loading-variant="list|text|grid"` 可切换骨架屏形态。

**AppSkeleton** — 独立骨架屏；**AppEmpty** — 独立空状态。两者由 `AppState` 自动组合，也可以单独使用。

约定：任何列表页都要显式给出这三种状态，不能再出现「出错时一片空白」。

**AppTag** — 统一小标签：`<AppTag tone="warning">草稿</AppTag>`，支持 `primary/success/warning/danger/neutral` 与 `sm/md`。

### 组件颜色隔离

基础组件使用 `--ui-*` 变量，而不是直接使用个人页主题变量：

- 非个人页默认蓝色：`--ui-primary: #409eff`
- 个人页根节点把 `--ui-*` 映射到当前个人页主题，所以组件能跟随薄荷绿 / 暖橙 / 莫兰迪灰
- 收藏夹等固定薄荷绿页面可以局部覆盖 `--ui-*`，不会影响首页、搜索、通知等页面

## 五、全项目手机壳与等比缩放

`App.vue` 使用 `DeviceShell` 包裹所有用户端路由。逻辑画布固定为 `390×844`，外层设备尺寸只通过 `transform: scale()` 等比缩放，因此 SE、标准、Max 看到的页面结构和断点一致，不会重新排版。

规则：

- 用户端页面默认启用手机壳：状态栏 + 手机外框 + 固定逻辑画布
- 页面在 `.app-page` 内滚动，滚动高度与逻辑画布分离
- 手机浏览器宽度 ≤ 520px 时，手机壳自动变为全屏；桌面端保留手机外框
- 后台路由通过 `meta.deviceShell: false` 排除手机壳，继续使用桌面全宽布局
- 状态栏包含时间、信号、5G、WiFi、电量，位于页面内容画布外部

**新增页面约定**：普通用户页面自动继承手机壳，不需要单独处理；只有后台等桌面型页面设置 `deviceShell: false`。

### 仍保留写死色值的位置（有意为之）

| 色值 | 位置 | 为什么保留 |
| --- | --- | --- |
| `#4f8a48` / `#e6f2e4` | 海报 Canvas 绘制 | **canvas 不认 `var()`**，替换会直接画错 |
| `#fff` / `#ffffff` | 按钮上的白字、卡片白底 | 通用白，不需要主题化 |
| `#667eea` / `#764ba2` | 头像/按钮渐变 | 独立的设计元素，不属于主题色 |
| `#e67833` | 详情页暖橙强调 | 详情页自己的配色，未纳入主题 |

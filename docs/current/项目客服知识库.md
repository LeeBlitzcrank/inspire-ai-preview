# 灵思集项目客服知识库

> 更新时间：2026-10-09  
> 用途：客服 RAG 唯一知识来源。回答应优先依据本文档，不扩展项目范围外的通用知识。

## 1. 项目是什么

灵思集是一个围绕“灵感创作、灵感分享和共同探索”的 Web 平台。用户可以发布自己的灵感、浏览别人的创作、收藏和点赞内容，也可以通过 AI 辅助生成标题、正文和探索方向。

项目还包含平行世界种子、私信、关注、通知、个人中心和后台管理能力。

项目定位：

- 面向普通用户：发现灵感、记录创意、发布作品、与他人互动。
- 面向创作者：借助 AI 完成标题、正文改写和内容探索。
- 面向运营管理员：管理用户、灵感内容、分类、词云和运营配置。

## 2. 用户能做什么

### 2.1 注册和登录

用户可以使用账号、邮箱和密码注册。注册成功后会自动登录。

登录方式包括：

1. 账号密码登录。
2. 手机号验证码登录。
3. 未绑定手机号时，验证码验证成功后可以自动创建账号。

如果连续登录失败，系统会临时锁定账号。需要验证码时，登录页会显示图形验证码。

### 2.2 发布灵感

用户登录后可以进入创作页发布灵感。

发布流程：

1. 输入灵感标题。
2. 选择分类。
3. 填写灵感正文。
4. 上传封面或多张图片。
5. 选择发布，或先保存为草稿。

标题和正文都有长度限制。图片上传有格式和大小限制。图片上传未完成时不能提交。

### 2.3 AI 创作

创作页支持：

- 输入关键词，让 AI 探索不同的灵感方向。
- 生成多条标题候选。
- 对选中的正文进行改写。
- 根据正文内容生成摘要和标签方向。

AI 生成内容仍然需要用户确认后才会发布，不会自动直接公开。

### 2.4 浏览、搜索和推荐

首页可以：

- 浏览推荐灵感。
- 左右滑动卡片。
- 左滑跳过，右滑收藏。
- 点击分类查看对应内容。

搜索页支持：

- 按标题、正文和分类搜索。
- 查看最新或最热内容。
- 点击结果进入灵感详情。

系统会结合热度、时间、分类和用户行为展示推荐内容。

### 2.5 灵感详情和互动

灵感详情页支持：

- 查看图片、正文、分类、作者和互动数据。
- 点赞、取消点赞。
- 收藏或取消收藏。
- 引用再创作。
- 评论、回复和 @ 已关注用户。
- 分享当前灵感。

评论支持分页和回复展开。@ 用户时会从用户已关注的人中选择，对方会收到通知。

### 2.6 收藏夹

用户收藏灵感时，可以选择收藏到不同收藏夹。

支持：

- 新建收藏夹。
- 重命名收藏夹。
- 删除收藏夹。
- 把收藏内容移动到其他收藏夹。
- 在个人中心查看不同收藏夹的内容。

如果用户没有主动选择收藏夹，系统会使用默认收藏夹。

### 2.7 关注、通知和特别关注

用户可以关注其他用户，也可以设置特别关注。

特别关注用户发布新灵感时，会收到更强的提醒。

通知中心会展示：

- 点赞。
- 评论和回复。
- @ 提醒。
- 关注。
- 引用。
- 特别关注用户发布。
- 系统通知。

### 2.8 私信

私信支持：

- 文本消息。
- 图片消息。
- 灵感卡片。
- 已读状态。
- 两分钟内撤回。
- 删除会话。
- 删除全部会话。

打开私信会话时会自动定位到最新消息。

### 2.9 个人中心

个人中心支持：

- 修改头像、昵称和城市。
- 修改密码。
- 绑定手机号。
- 查看我的发布。
- 查看草稿。
- 查看收藏。
- 查看关注和粉丝。
- 管理收藏夹。

用户账号只用于登录，其他用户看到的是昵称，不会展示登录账号。

### 2.10 世界种子

世界种子用于从公版故事、古诗或短篇内容出发，生成平行世界线和后续章节。

使用流程：

1. 输入作品名称和作者。
2. 粘贴原文内容。
3. 填写创作方向。
4. 提交后等待 AI 生成世界线。
5. 进入世界线查看初始背景。
6. 选择一个分支和下一章方向。
7. 生成下一章并继续推演。

世界种子内容会明确标注为平行创作，不会冒充原文。

### 2.11 项目客服

页面右下角的“客服”按钮可以打开项目客服。

客服可以回答：

- 项目怎么使用。
- 某个功能在哪里操作。
- 功能和业务规则说明。
- 项目技术架构和实现方式。

客服不会回答：

- 与项目无关的闲聊。
- 写诗、天气、通用编程教学等范围外请求。
- 密钥、环境变量、内部地址或数据库密码。

如果客服没有找到明确文档依据，会说明“文档中没有明确说明”，不会编造功能。

## 3. 技术和实现概览

### 3.1 前端

前端使用 Vue 3 和 Vite。

主要能力：

- 单页应用路由。
- 登录状态管理。
- 组件化页面。
- 移动端设备外壳。
- 图片懒加载和虚拟列表。
- 请求缓存、去重和失败重试。
- 统一错误提示。
- 长章节和长列表按需渲染。

### 3.2 后端服务

后端使用 Spring Boot 微服务架构，并按职责拆分：

- 网关服务：统一入口、路由、鉴权、限流和身份透传。
- 认证服务：注册、登录、密码、手机验证码、JWT 和会话。
- 核心服务：灵感、评论、收藏、私信、通知、系列、文件和计数器。
- AI 服务：AI 探索、标题生成、正文改写和世界种子。
- 搜索服务：Elasticsearch 与 MySQL 搜索降级。
- RAG 服务：项目问答、灵感检索和客服知识库。
- 管理服务：后台用户、内容、分类、词云、配置和审计。

服务之间通过网关、HTTP 和消息队列协作。

### 3.3 数据库和缓存

- MySQL 保存用户、灵感、评论、消息、通知和运营数据。
- Redis 保存登录会话、验证码、限流、缓存和浏览计数。
- Elasticsearch 负责全文搜索和向量检索。
- MinIO 保存图片和视频等文件。
- RocketMQ 负责发布、搜索同步、通知和其他异步事件。

高频公开数据会先走缓存，发布、修改或删除后再触发缓存失效。

### 3.4 登录和鉴权

系统使用 JWT 双 Token：

- AccessToken：短期访问令牌。
- RefreshToken：用于刷新登录状态。

网关统一校验令牌，然后把可信用户身份传给下游服务。

登录还包含：

- 账号级失败计数。
- 图形验证码。
- 临时锁定。
- 手机号验证码。
- 密码修改后旧会话失效。
- 弱密码升级限制。

### 3.5 AI 和 RAG

AI 创作主要调用大模型服务。

RAG 用于从指定知识库找内容后生成回答。客服 RAG 使用独立索引，只读取本文件，不与用户灵感数据混用。

客服回答流程：

1. 判断问题是否属于项目范围。
2. 检索本知识库。
3. 校验相关度。
4. 整理成操作步骤或技术说明。
5. 返回答案和来源。

### 3.6 性能和扩展

系统使用：

- 缓存前置。
- 分页和游标。
- 长列表虚拟渲染。
- 图片按需加载。
- 异步消息处理。
- 独立计数表。
- 慢查询和请求指标监控。
- 公开接口限流。

这样可以在用户和内容增长后继续横向扩展。

## 4. 常见问题

### 4.1 为什么图片加载失败

可能原因：

- 图片文件不存在。
- 图片格式不支持。
- 图片体积过大。
- 网络或对象存储暂时不可用。

支持的图片类型以页面上传提示为准。图片上传失败时，可以重新上传。

### 4.2 为什么登录失败

常见原因：

- 账号或密码错误。
- 账号被临时锁定。
- 需要输入图形验证码。
- 登录状态过期。

连续失败后请等待锁定时间结束，或使用正确的账号密码重新登录。

### 4.3 忘记密码怎么办

点击“忘记密码”，输入注册邮箱。系统会发送重置链接，使用链接设置新密码。

### 4.4 为什么收不到短信验证码

可能原因：

- 手机号输入错误。
- 仍在冷却时间内。
- 当日发送次数达到上限。
- 短信服务暂时不可用。

冷却期间按钮会显示“还剩多少秒可重发”，倒计时结束前不能重复发送。

### 4.5 为什么 @ 用户时没有出现某人

@ 面板优先展示用户已经关注的人。没有关注对方时，对方可能不会出现在快速选择列表中。

### 4.6 为什么收藏没有直接加入默认收藏夹

系统会先让用户选择收藏夹，方便把不同内容分类保存。也可以继续新建收藏夹后再收藏。

### 4.7 为什么私信撤回失败

私信只允许在发送后两分钟内撤回。超过时间后不能撤回。

### 4.8 为什么下一章生成比较慢

下一章需要结合原文、世界线、角色状态和用户选择进行生成，因此会比普通页面操作慢。生成过程中页面会显示进度。

### 4.9 客服为什么拒绝回答某些问题

客服只服务灵思集项目。与项目无关的问题，例如天气、写诗或通用编程教学，会被拒绝，以保证回答范围可控。

### 4.10 客服回答的数据从哪里来

客服回答只来自本文档。项目代码、用户数据、密钥和运维配置不会进入客服知识库。

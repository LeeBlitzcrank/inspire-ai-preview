灵感详情编辑按钮：三种位置

作者卡片只保留用户信息和关注关系，编辑入口改放到文章自己的操作区域。

A · 顶部操作 B · 标题操作区 C · 正文末尾
方案 A · 顶部操作最标准

编辑按钮放在详情页右上角，只有作者自己可见，作者卡片完全不受影响。

方案 B · 标题操作区最明确

标题下方放“已编辑”和“编辑”，编辑对象明确，和修改记录也能放在一起。

方案 C · 正文末尾最克制

正文结束后放作者自己的操作卡，不干扰阅读，但需要滑到下面才能看到。

建议：如果希望入口稳定、明显，选 A 或 B；如果不想打扰读者，选 C。

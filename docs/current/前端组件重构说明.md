> 更新时间：2026-09-29

## 一、重构原则

本次重构不按照“HTML、CSS、JS 必须分文件”机械拆分，而是按照职责和复用范围拆分：

- Vue SFC 继续保留 `template + script setup + scoped style` 结构。
- 组件私有样式保留 `scoped`，不放入全局样式。
- 页面私有交互逻辑保留在页面或页面级 composable。
- 可复用状态和流程进入 `composables`。
- 页面直接请求收敛到 `api` 模块。
- 纯格式化和无状态函数进入 `utils`。
- 不为减少行数创建没有真实职责的中间文件。

## 三、已完成的职责拆分

### 1. 页面 scoped 样式外置

六个超长页面的样式已移动到对应页面目录：

```text
pages/detail/styles/inspire-detail.css
pages/create/styles/create.css
pages/messages/styles/messages.css
pages/personal/styles/personal.css
pages/search/styles/search.css
pages/home/styles/home.css
```

页面使用：

```vue
<style scoped src="./detail/styles/inspire-detail.css"></style>
```

样式作用域未改变，也没有把页面样式集中进全局 CSS。

### 2. 私信页

```text
pages/messages/composables/useMessageRealtime.js
pages/messages/composables/useMessageComposer.js
pages/messages/utils/messageTime.js
```

- `useMessageRealtime`：SSE 连接、断线重连、30 秒兜底轮询和页面可见性恢复。
- `useMessageComposer`：文本、图片、灵感卡片发送和撤回。
- `messageTime.js`：会话列表和消息时间格式化。

### 3. 创建页

pages/create/composables/useCreateVoiceInput.js

- `useCreateMedia`：图片压缩、滤镜烘焙、视频上传、重试、压缩、裁剪、封面和九宫格。

## 四、接口层调整

新增：

```text
api/auth.js
  getIpLocation()
```

Personal 页面不再直接调用 `fetch('/api/auth/ip-location')`，统一走请求封装，保证 Token、自动刷新和错误处理一致。

## 五、保留 scoped 样式的原因

没有把所有 CSS 移入 `styles`：

- 页面私有样式不会污染其他页面。
- 删除页面时可以同时删除对应 CSS。
- 避免全局 CSS 持续膨胀。
- 避免类名冲突和跨页面回归。

`src/styles` 继续只负责设计变量、全局覆盖和公共弹窗规则。

## 六、后续维护

所有原页面已低于 600 行，后续以稳定性和职责边界为准，不再为了行数继续强制拆分。

后续仅在这些条件出现时继续拆：

- 单个子组件再次超过 600 行。
- 页面同时承担两个以上独立业务域。
- 同一段逻辑被第三个页面复用。
- 某个组件可以独立测试或独立复用。

拆分标准仍是组件拥有独立模板、状态和交互边界，不按行数硬拆。

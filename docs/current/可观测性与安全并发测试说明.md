# 可观测性与安全并发测试说明

> 更新时间：2026-09-24  
> 范围：traceId、慢 SQL、缓存命中率、MQ 积压、ES 写入延迟、接口 P95/P99，以及安全与并发自动化测试。

## 一、统一 traceId

网关新增最高优先级过滤器：

```text
TraceIdGlobalFilter
```

业务服务新增 Servlet 过滤器：

```text
TraceIdFilter
```

规则：

- 请求没有 `X-Trace-Id` 时自动生成 32 位 trace ID。
- 客户端传入非法 trace ID 时忽略并重新生成，避免日志注入。
- 网关把 trace ID 转发给下游。
- 网关响应在提交前统一覆盖 `X-Trace-Id`，避免出现重复响应头。
- 业务日志 pattern 已加入：

```text
[traceId=%X{traceId:-}]
```

示例：

```text
2026-09-24 02:31:41.699 INFO [traceId=9136fe2c935245588f218848ffcf1edd] ...
```

## 三、指标

### 接口 P95/P99

Micrometer 自动记录：

```text
http_server_requests_seconds_bucket
```

P95：

```promql
histogram_quantile(
  0.95,
  sum by (le, uri) (
    rate(http_server_requests_seconds_bucket[5m])
  )
)
```

P99：

```promql
histogram_quantile(
  0.99,
  sum by (le, uri) (
    rate(http_server_requests_seconds_bucket[5m])
  )
)
```

### 缓存命中率

Redis CacheManager 已开启统计。

指标：

```text
cache_gets_total
```

计算：

```promql
sum(rate(cache_gets_total{result="hit"}[5m]))
/
clamp_min(
  sum(rate(cache_gets_total{result=~"hit|miss"}[5m])),
  1
)
```

### ES 写入延迟

`EsSyncService` 已记录单条写入和批量写入耗时：

```text
inspire_es_write_latency_seconds_bucket
inspire_es_write_errors_total
```

P95：

```promql
histogram_quantile(
  0.95,
  sum by (le, operation) (
    rate(inspire_es_write_latency_seconds_bucket[5m])
  )
)
```

同时，批量写入不再使用 `refresh=true`，只有存在写入时才触发 refresh。

### MQ 消息量与积压

指标：

```text
inspire_mq_send_total
inspire_mq_send_latency_seconds_bucket
inspire_mq_consume_total
inspire_mq_consume_last_message_age_seconds
inspire_mq_consumer_lag
```

积压查询：

```promql
max by (group, topic) (inspire_mq_consumer_lag)
```

当前覆盖：

```text
consumer_register  -> topic_user_register
consumer_behavior  -> topic_user_behavior
consumer_publish   -> topic_inspire_publish
```

宿主机位置：


## 四、自动化测试

### 后端单元测试

运行：

```bash
cd backend
mvn test -pl inspire-common,inspire-core -am
```

覆盖：

- 内部身份签名正确性。
- 篡改角色和过期时间戳被拒绝。
- 无签名伪造 `X-User-Id` / `X-User-Role` 被拒绝。
- 私信超过 2 分钟不能撤回。
- 公共列表分页基础行为。
- 不存在的详情返回异常。

### Playwright 安全与并发测试

文件：

```text
frontend/tests/e2e/security.spec.js
```

运行：

```bash
cd frontend
npm run test:e2e
```

覆盖：

- 网关返回唯一 `X-Trace-Id`。
- 绕过网关伪造下游身份头返回 401。
- SSRF 内网代理被拒绝。
- 远程 URL 上传拒绝 `127.0.0.1`。
- 用户不能修改他人的灵感。
- 并发点赞只能成功一次。
- 并发收藏只能成功一次。
- 发布后公共列表缓存立即出现新内容。
- 删除后公共列表缓存立即移除内容。
- 原登录、发布、图片上传、图片删除、评论主链路。

当前运行结果：

```text
4 passed
```

## 五、当前限制

1. 还未部署 Prometheus Server 和 Grafana，当前只提供标准 Prometheus 指标端点。
2. MQ 积压采集依赖 RocketMQ Admin API，RocketMQ 不可用时指标保持最后一次值。
3. traceId 已覆盖 HTTP 链路，尚未自动写入 MQ 消息体的链路上下文。
4. 慢 SQL 已落文件，尚未接入 ELK 或 Loki 做集中检索。
5. 并发测试覆盖重复点赞/收藏，尚未加入更高并发和大数据量压力模型。
